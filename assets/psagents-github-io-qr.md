# QR code — psagents.github.io

**URL encoded:** https://psagents.github.io/

| File | Use |
|------|-----|
| `psagents-github-io-qr.png` | Slides, posters, print |
| `psagents-github-io-qr.svg` | Vector / lossless resize |

Regenerate:

```bash
qrencode -l M -s 12 -m 2 -t PNG -o assets/psagents-github-io-qr.png 'https://psagents.github.io/'
qrencode -l M -s 12 -m 2 -t SVG -o assets/psagents-github-io-qr.svg 'https://psagents.github.io/'
```
